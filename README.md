# 🤖 AI SQL Assistant

AI-powered SQL assistant that converts natural language into SQLite queries using Python, OpenAI API, and Streamlit.

## Features
- Convert natural language to SQL
- Execute SQL against SQLite
- Business analytics using JOINs
- Live Streamlit interface

## Technologies
- Python
- OpenAI API
- SQLite
- Streamlit
- Pandas
